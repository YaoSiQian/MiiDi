# MiiDi 实验报告

> 配套材料：评测方法详见 [evaluation.md](evaluation.md)；完整逐样本结果表见 [evals/results/results.md](../evals/results/results.md)；统计汇总见 [evals/results/summary.md](../evals/results/summary.md)；有效性验证实验数据见 [evals/results/experiments.md](../evals/results/experiments.md)。

## 1. 场景选择：为什么是「自然语言 → MIDI」

### 1.1 场景描述

MiiDi 的用户输入是一句自然语言（"雨夜的咖啡馆，慵懒的 Lo-Fi"）加上一个风格包（pop / classical / jazz / lofi / touhou），系统输出一份多轨 MIDI：六轨编配（旋律、贝斯、鼓、和声、副旋律、色彩）、2-3 分钟的结构完整作品，可直接导入任意 DAW 再创作。

### 1.2 选择理由

**（1）输出可机器验证，评估不依赖人工。** MIDI 是符号化、强结构化的产物：音高/力度有硬边界（0–127），音符必须落在节拍网格上，轨内不能重叠，和声要贴和弦标记，乐器有可演奏音域。这些约束全部可以写成确定性代码。相比之下，自由文本或图像生成的"质量"评估本身就需要 AI 或人来兜底，评测体系容易循环论证。符号音乐场景允许我们把"及格线"做成纯程序，把主观维度隔离给 Judge，评估体系的每一层都可审计。

**（2）任务对 LLM 构成真实的端到端压力。** 一首 16–32 小节的作品是 500–1500 个音符的结构化 JSON 输出，同时要求：

- 长程一致性：调性贯穿全曲、和声进行与每小节和弦标记对齐、动机在段落间再现；
- 显式约束遵守：BPM、调性、时长、指定乐器；
- 隐式领域知识：编配惯例（Bass 不抢旋律音区）、风格节奏型（爵士 swing、东方碎鼓）、终止式写法。

这比"生成一段代码"更能暴露模型在长结构化输出上的衰减规律——后者有编译器和测试兜底，而音乐的一致性约束分散在每个音符上。

**（3）失败可归因。** 五阶段流水线（Plan → Core → Arrange → Coordinate → Review）把生成拆成可检查的中间产物：简报、逐轨音符、编配命令、评估报告。一个失败样本可以被定位到"和声支撑不足"或"段落对比缺失"这样的具体维度，而不是笼统的"不好听"，这让失败模式归纳成为可能。

**（4）人机协作姿态真实。** 符号音乐是可编辑的中间产物而非最终消费品。AI 当"初稿生成器"、人做最后的音乐决策，这是生成式 AI 当前真实可靠的使用方式，也是我们设计分阶段预览、版本回滚、自然语言单轨修改的产品依据。

## 2. AI 应用方案：生成–评估–修订闭环

系统采用"生成 → 评估 → 修订"的闭环架构，评估器既是交付质量的裁判，也是生成流程的内环（Review 阶段直接消费规则评估报告做定点修补）。

```
用户 Prompt + 风格包(SKILL.md/harmony/rhythm/instruments)
   │
   ▼
① Plan   ── LLM 产出 MusicBrief（调性/BPM/段落/逐小节和弦/配器表）
   │
   ▼
② Core   ── 逐轨生成 melody → bass → drums（后轨可见前轨上下文）
   │
   ▼
③ Arrange ── 逐轨生成 harmony → counter → color（可见全部 Core 轨）
   │
   ▼
④ Coordinate ── LLM 分析整体平衡，输出结构化命令（section_mute / octave_shift / density_reduce）
   │
   ▼
⑤ Review ── 规则评估器打分 → 违规清单回灌 LLM 定点重写（最多 2 轮）
   │
   ▼
MIDI 渲染 + 双轨评估（R_rule × gates + J1/J2/J3 → composite）
```

关键工程决策：

| 决策 | 理由 |
|------|------|
| LLM 输出一律过 `normalize` + 硬校验 | LLM 的 JSON 在边界值上不可信任（越界音高、重叠音符、断裂结构），修复器与校验器把"格式合法性"从模型能力问题变成工程问题 |
| 逐轨生成而非整曲一次生成 | 单轨 50–150 音符是长结构化输出的可靠上限；整曲一次生成在长作品上截断率和幻造率显著上升 |
| 评估器内嵌进生成流程（Review） | 评估不是事后仪式而是生成反馈信号，规则违规可以立刻定点修复 |
| 会话版本快照 | 每阶段落盘、可续跑可回滚，长流水线的中断成本从"全部重来"降为"从断点继续" |
| LLM 双协议客户端 | OpenAI 兼容 Responses API 与 OpenCode Zen 免费档（Chat Completions）自动切换，零配置可跑通全流程 |

## 3. 评估维度设计依据

### 3.1 四条设计原则

- **P1 可复现性优先**：规则轨是纯函数（同一输入恒同输出，E2 验证），零 API 成本，可以放进 CI。
- **P2 假设被评对象会作弊**：LLM 生成器会复读凑篇幅、堆十六分音符刷"复杂度"、铺满音域装"宽广"。加权平均分对这类退化不敏感（一个轴烂其他轴可以补），所以反退化门做成**乘法**——任何一门归零，总分归零。
- **P3 主客观互补**：规则轨回答"错了没有"（音阶、和弦、音域、网格），Judge 轨回答"好不好"（风格对味、遵循意图、有音乐性）。两者覆盖面不重叠，相关性是实证问题（见 §6）。
- **P4 归因可解释**：每轴输出子指标明细（如 harmony 轴的 scale_adherence / chord_support / cadence_rate），每个 Judge 维度输出逐项判定与证据。失败样本可以定位到子指标级别。

### 3.2 规则轴权重依据

| 轴 | 权重 | 权重理由 |
|----|------|----------|
| A1 格式 | 资格门 | 格式错误的 MIDI 不可用，一票否决，不参与加权 |
| A2 和声 | 0.30 | 调性/和弦错误是听感上最先暴露、最不可容忍的错误；且和声约束可完全形式化 |
| A3 声部 | 0.20 | 音域越界与平行五八度是编曲硬伤，但个别越界可以接受，用连续扣分而非一票否决 |
| A4 节奏 | 0.20 | 网格吸附与鼓型是律动的下限；密度匹配必须按风格参考值，所以轴计算需要风格包参数 |
| A5 结构 | 0.20 | 段落覆盖与对比决定"完整作品感"，但结构相似度阈值带有风格主观性，权重不宜更高 |
| A6 动态 | 0.10 | velocity 层次影响表现力但不是硬错误，权重最低 |

### 3.3 反退化门与真实作弊模式的对应

| 门 | 针对的作弊模式 | 机制 |
|----|----------------|------|
| G_repetition | 复制粘贴整段凑篇幅 | 相邻音符 4-gram 重复率，>30% 开始线性惩罚 |
| G_density | 十六分音符轰炸刷复杂度 / 空洞凑小节 | 全曲密度 vs 风格参考区间，双向惩罚（下限 0.5，不归零） |
| G_balance | 凑轨数：某轨只放几个音 | 轨道时值占比最小值，<10% 扣分 |
| G_spread | 用几个极端音撑宽音域 | 去头尾修剪后音域 < 原音域 60% 判为"虚假宽度" |

设计取舍：G_density 下限 0.5 而非归零——密度偏移常见于风格实验（如东方系的超高密度），直接归零会误杀；G_repetition 允许到 0.30——流行音乐本身就依赖重复，过严会惩罚正常的段落再现。

### 3.4 Judge 轨的防方差设计

LLM 评委的两大风险是**分数漂移**和**话术骗分**，三个维度的提示词都做了针对性处理：

- **J1 风格符合度**：不问"像不像爵士"，而是注入风格包的 8 项检查清单，逐项 yes/partial/no 并要求给出轨道名+小节数的证据——清单化判定把开放比较变成封闭核对，证据要求压缩了空话空间；
- **J2 提示遵循度**：显式约束（BPM/调性/时长/乐器）先由正则从 prompt 抽出，再逐项三值判定（satisfied/violated/unaddressed）——约束提取与判定分离，避免评委凭印象打分；
- **J3 音乐性**：1–5 档锚点 rubric，每档附可核查特征（"第 3 档 = 技术正确但像音序器直出"），并把规则轴得分摘要给评委做参照——锚点比开放打分的跨样本一致性高得多。

### 3.5 合成分

`composite = 0.6 × R_rule + 0.4 × mean(J1, J2, J3)`

规则轨权重高的理由：可复现、可审计、无法靠话术骗分，适合作为及格线主体；Judge 轨负责补足风格与审美维度。0.6/0.4 使格式硬伤（R_rule 归零）足以把总分压进"不可用"区间，同时一段技术上无可挑剔但毫无音乐性的作品也不会超过 60 分。

## 4. 评测实施

### 4.1 样本集

38 个样本，四个类别覆盖不同能力面：

| 类别 | 数量 | 考察点 | 示例 |
|------|------|--------|------|
| basic | 20（5 风格 × 4） | 各风格的基础生成质量与风格特征 | "A bright, upbeat pop song about the joy of a sunny morning walk" |
| constraint | 8 | 显式约束遵守（BPM/调性/时长/乐器） | "A pop song at exactly 120 BPM in the key of G major, 32 bars long" |
| hard | 6 | 强乐理约束下的长程一致性 | "A full jazz piece using only ii-V-I progressions throughout all sections" |
| adversarial | 4 | 自相矛盾/无意义输入的优雅降级 | "Write a 300 BPM lullaby that is both extremely fast and very soothing" |

### 4.2 实验过程与环境

- **流程**：每个样本独立走完整五阶段流水线（约 7–11 次 LLM 调用），随后规则评估 + 三维 Judge（3 次调用）；无人工干预；
- **模型**：OpenCode Zen 免费档（OpenAI 兼容 Chat Completions 协议，模型经 `MODEL_NAME` 环境变量注入，默认 `hy3-free`）；生成与评委使用同一模型（局限见 §10）；
- **并发**：4 路并发，单样本全程 15–30 分钟，全量 38 样本约 4 小时；
- **产物**：每样本落盘 `composition.json` / `rule_report.json` / `judge_report.json` / MIDI，评分汇总至 `results.csv`——全部分析基于这些原始产物，可复核；
- **评测过程中的两处修正**（对结果有效性的诚实声明）：① 首轮发现 `evaluate_judge` 未收到用户 prompt、J2 全部退化为空洞高分（见 §9 模式 2），修复调用点后对全部 29 个完成样本仅重评 J2 维度（输入不变，仍是同一批 composition），J1/J3 与规则轨未受影响；② 8 个生成失败样本做了失败重测用于归因（主表保持首轮原样，重测数据单列，见 [rerun_failed.md](../evals/results/rerun_failed.md)）。

### 5. 有效性验证（E1 / E2 / E3）

基准作品：`classical_basic_01`（24 小节、4 轨、133 音符、R_rule = 77.5，无门击穿），脚本与数据见 [evals/results/experiments.md](../evals/results/experiments.md)。

**E2 确定性 ✓**：同一作品独立评估 3 次，R_rule 三次完全一致（极差 = 0.000000，标准差 = 0.000000）。规则轨是纯函数，可放进 CI 做回归门禁。

**E1 区分度（部分通过，失败项可机制化解释）**：

| 退化操作 | 目标轴 | 实际降幅 | 判定 |
|----------|--------|----------|------|
| scatter_pitch | harmony / voice | −0.52 / −0.39 | ✓ 强检测 |
| remove_track | harmony / voice | −0.02 / 0.00 | ✗ 不敏感 |
| scatter_onset | rhythm | n/a（A1 格式门直接拦截） | △ |
| repeat_first_bar | structure / rhythm | 0.00 / −0.04 | △ |

**E3 对抗性（6/7 检出，1 项反升）**：

| 退化操作 | R_rule 变化 | 检出机制 |
|----------|-------------|----------|
| scatter_pitch | −20.3 | 和声/声部轴大幅下降 |
| scatter_onset | −77.5（归零） | A1 格式门：抖动产生轨内音符重叠 |
| repeat_first_bar | −77.5（归零） | G_repetition 门：4-gram 重复率爆表 |
| remove_track | **+1.7（反升）** | 被删的是最弱的 color 轨 |

三点机制结论（这也是把"归因失败"与"系统失效"区分开的地方）：

1. **轴归因失败 ≠ 总分失守**。repeat_first_bar 在 structure 轴上几乎无感（复制本身提高了段落间相似度），但 G_repetition 门直接把总分归零——系统级检测靠的是乘法门兜底，而不是轴归因。
2. **scatter_onset 的检测发生在 A1 格式层**（±60 tick 抖动制造音符重叠 → invalid → R_rule=0），节奏轴从未参与评估。这说明"资格门优先"的设计把节奏污染拦截在了更便宜的层。
3. **「删轨」是评估器的真实盲区，且与删哪轨无关**。被删的是最弱的 color 轨时 R_rule 反升 1.7；实测删 bass 主干轨 R_rule 仅下降 0.8（harmony 轴 −0.014——chord_support 的满分平台区 [0.5, 0.8] 吸收了 accompaniment 质量的损失）；删旋律主轨 R_rule 反而上升 1.4（密度回归参考区间、段落相似度重构）。规则轴用 band 平台区换取容错性的代价是对"整轨消失"这类结构性退化的低敏感；G_balance 只覆盖"存在饿死轨"，不覆盖"主干轨被删"。若要提高该维度敏感度，需要引入轨数/角色完整性作为独立检查项，这是后续迭代方向。**（后续迭代已落地：G_balance 现已引入核心轨在场性检查，见下方 E1b。）**

**E2-Judge 评委轨重复一致性（新增）**：规则轨的 E2 只能证明"纯代码确定"（平凡结论），评委轨的一致性才是 Judge 分数可否信赖的问题。实验：8 个已完成评测样本（5 曲风 basic 各 1 + constraint / hard / adversarial 各 1）冻结输入（composition.json 与 prompt 的 SHA-256），每样本独立重复 3 轮 J1/J2/J3（温度 0.0，与主评测一致），数据见 [judge_consistency.md](../evals/results/judge_consistency.md)：

| 指标 | 数值 |
|------|------|
| J1 / J2 / J3 每维 mean(std) | 2.96 / 5.08 / 3.01（百分制） |
| composite 单样本极差 | ≤ 2.53 |
| J1 风格清单逐项一致率 | 82% |
| J2 约束判定一致率 | 91% |
| J3 档位二次加权 κ（合并成对比较） | 0.71 |

诚实披露：classical_basic_01 有 2/3 轮因 Judge 回复 JSON 解析失败被排除（高密度古典作品的 composition JSON 使 Judge 回复格式脆弱），聚合基于其余 7 样本。**结论**：评委轨处于中等波动档——排序与分组结论可用（J3 κ=0.71 属"较好一致性"区间），但单分差在 8 分内的样本不应据单次 Judge 评分定高下；已知缓解措施是对争议样本取多轮中位数。

**E1b 三档生成样本判别力（新增）**：每曲风 1 个样本构造原始 / 轻度（音高随机化）/ 重度（音高随机化+首小节复制+删旋律核心轨叠加）三档，规则轨 + Judge 轨都评，数据见 [e1b_tiers.md](../evals/results/e1b_tiers.md)：

| 结论 | 证据 |
|------|------|
| **重度档 5/5 全检出** | severe composite 全部大幅低于 original（classical 78.5→0、jazz 33.1→11.3、lofi 43.3→20.7、pop 42.5→20.3、touhou 25.0→14.9；classical 的 severe 因重复门归零） |
| **轻度档方向不可靠** | 高分基线严格下降（classical 78.5→58.5），但低分基线反而上升（pop 18.7→56.1 的 R_rule、touhou 25.0→30.1 的 composite）——随机 48–84 音高比原曲更贴合，与 E5 scatter 探针、E3 删轨反升同属"对劣化方向不敏感"的边界条件 |
| **删核心轨探针 3/5 检出** | classical −30.2 / lofi −8.3 / pop −10.2；jazz +9.9、touhou +1.6 未检出——低分基线的 band 平台区吸收超过 0.6 惩罚系数，相比旧评估器的 +1.7 反升已大幅收敛但未归零，加强惩罚列为后续方向 |

composite 层面的严格排序在 2/5 样本成立、违反 2/5、1 个因 Judge 调用失败剔除；违反的 2 个都由轻度档反向造成。**结论**：评估器对"重度劣化"的判别可靠，对"低分样本上的轻度劣化"方向不可靠——这与 E2-Judge 的"单分争议需多轮仲裁"、E5 的顺序无关性共同构成评估器边界的完整画像。

**E4 异构 Judge 消自我偏好（新增）**：同 8 样本由生成同源 Judge-A 与 Zen 免费档异构 Judge-B 独立评分，数据见 [e4_hetero_judge.md](../evals/results/e4_hetero_judge.md)。composite 层面跨模型 Pearson = 0.934 / Spearman = 0.690——总分排序可迁移；维度级 J1（Pearson 0.68 / Spearman 0.53）与 J2（0.59/0.59）中等相关，J3 仅 0.073——音乐性维度跨模型分歧最大；均值差显示 Judge-A 在 J2 上系统性宽约 6.6 分。§10 的"生成与评判同源"局限据此升级为量化表述。

**E3 扩充：对抗样本 4→12 条与门误伤密度（新增）**：新增 8 条与四道门一一对应的对抗样本（复读凑时长 / 十六分音符轰炸 / 空轨凑数 / 极端音域撑宽 / 话术骗分 / 复制鼓 loop / 极低密度 / 无核心轨 pad），全部过完整流水线实测（含新回填的拦截层标签列）：

- **明确检出 6/8**：A1 格式门拦截 1（话术骗分型）、流水线生成失败（优雅降级）2、乘法门拦截 3——其中十六分音符轰炸型被 G_repetition/G_density/G_balance 三重门同时击中（R_rule→0）；
- **部分检出 1**：极低密度型触发 G_repetition(0.917)+G_density(0.5)，但 composite 46.6 仍属中等；
- **未检出 1**：极端音域撑宽型（adversarial_08，R=71.8）——生成端未真正实现极端跳进，G_spread 未触发，属提示词-评估器间的语义落差，已如实披露。

门误伤密度（成对汇报的另一侧）：14 条干净 basic 样本中 12 条（86%）至少有一个门 ≤ 0.8，主要贡献者是 G_repetition（lofi/touhou 律动本身的复制性）与 G_balance 的 0.4 地板。**对抗检出与干净样本误伤来自同一套敏感度**——门阈值偏紧是 evaluation.md「已知校准项」的又一佐证，读分时应把门触发视为"密度信号"而非"作弊证据"。

**总体验证结论**：确定性满分；对抗检测 4/4 操作在总分层面全部检出（含两项归零）；轴级归因 2/4 达标。规则轨作为"及格线裁判"可信，作为"逐轴归因器"需结合门控解读。评委轨重复一致性实测为中等波动（J3 κ=0.71），排序结论可用、单分争议需多轮仲裁。


## 6. 评测结果

### 6.1 总体

- 38 个样本中 **29 个完成全流程**（76%），8 个生成失败、1 个格式无效（hard_04，见 §8）；
- 完成样本 composite 均值 **42.7**（R_rule 28.0，Judge 均值 64.8）；
- 分段分布：60–79「合格」5 个，40–59「勉强」8 个，20–39「较差」16 个，无 80+ 也无 20 以下——**当前模型档位下，产物定位是"可用初稿"而非"成品"**。

### 6.2 主客观相关性

Pearson r(R_rule, J_mean) = **0.057**（n=29）——双轨几乎正交。这印证了双轨设计的必要性（两条轨在测不同的东西），也带来一个重要警示：规则轨说"好"的，Judge 不一定买账，反之亦然。典型背离样本：touhou_basic_02（R_rule 2.4，J3=80）、adversarial_03（R_rule 7.7，J3=90）——听感原型尚可但内容层已退化；此类样本应当进入人工复听队列。

## 7. 评测结论

1. **端到端流程成立，产物定位为初稿**。76% 样本走完全流程；完成样本中 17% 达到"合格"线（60+），约 55% 落在 20–39。以"DAW 可编辑的初稿"标准看已经可用，以"直接可听"标准看还有明显差距。
2. **显式约束是当前方案的强项**。constraint 类样本在元数据层（BPM/调性/小节数）7/7 完全遵守——Plan-first 的任务分解把"数字型要求"的可靠性问题基本解决；失败集中在内容层的多样性上。
3. **复读是第一失败因素**。G_repetition 均值 0.519、最低 0；规则轴均值 70+ 的作品被它砍半是常态。反復不是边缘案例，是系统性行为。
4. **双轨正交（r=0.057）**意味着两个轨道都不能取消：规则轨抓得住"技术性退化"却测不了风格对味；Judge 能认可听感却对复读/门控问题完全钝感（它看不到重复检测）。合成分 composite 里两侧各占 0.4/0.6 的设计在数据上是成立的。
5. **生成可靠性是最大工程短板**。首轮全流程失败率 21%（8 失败 + 1 invalid）；重测归因显示其中 5 例为端点瞬时故障、3 例为 Core 阶段持续失败（空响应/JSON 非法，均集中在 pop/jazz 高密度编配）——持续失败率约 8%，与生成质量无关，但同样会中断交付链路，需要更细的"轨道级降级"策略（如跳过失败轨、以缺轨作品兜底）而非整段放弃。

## 8. 模型失败模式归纳与能力边界

| # | 失败模式 | 证据 | 机制 |
|---|----------|------|------|
| F1 | **流水线中途失败** | 8/38 样本 comp=None，集中于 pop_basic（3/4）与 jazz_basic（3/4） | 重测归因：5/8 为端点瞬时故障（重跑即恢复）；3/8 持续失败，全部发生在 Core 阶段——2 例「空响应重试耗尽」、1 例「JSON 非法重试耗尽」，均为高密度 pop/jazz 编配。详见 [rerun_failed.md](../evals/results/rerun_failed.md) |
| F2 | **越界一票否决** | hard_04：500+ 音符中 1 个超出曲长 480 tick → composite=0 | 越界音符由 Review 自修补阶段引入；A1 门零容错，模型对"绝对边界"（61440 tick）的保持能力不足 |
| F3 | **复读式填充** | constraint_01 五轴全绿（harmony 0.86/rhythm 0.96）但 G_repetition 0.22 → R_rule 19 | 材料多样性耗尽后循环利用动机凑满 32 小节；轴检测不到，只有 4-gram 门能抓 |

| F5 | **编配与音区偏差** | J1 清单失败 Top3：编制（item1）、音区（item2）、密度（item5） | 风格包声明了标准编制，但模型对"哪些声部该出现"的服从弱于对"写了的声部怎么写"的服从 |
| F6 | **评委单次方差与语义盲区** | J2 重评后分布 0–100；对抗样本全部 ≤15 分 | LLM 评委单次采样，无自洽性机制；且 J2 把"对矛盾约束的优雅违反"（300 BPM 摇篮曲被写成 120）判为 violated——对抗类样本的 J2 语义需要特判 |

**能力边界（按数据划定）**：

- **长度**：24 小节内结构完整性好（structure 均值 0.71+）；40+ 小节开始出现结构轴塌缩与复读累积，当前可靠上限约 32 小节；
- **密度**：≤20 音符/小节时门控安全；35+ 音符/小节（touhou）必然触发复读门；
- **格式**：绝大多数样本格式合法，但每首 500+ 音符中仍有 ~1 个音符级越界的概率，在 A1 一票否决下等价于整首报废；
- **约束**：BPM/调性/小节数等可枚举约束可靠；情感/意象类约束（J2 的主观判定项）目前只有 LLM 的定性判定，无硬数据支撑。

## 9. 实际评测中挖掘到的典型模式

**（1）约束强、内容弱的"可靠性倒挂"。** 最字面的要求（120 BPM、G 大调、32 小节）遵守率 100%，而最内在的要求（"别重复自己"）系统性失败。任务分解（Plan 先行）把可以变成检查表的要求都解决了，剩下的全是开放式生成问题——改进投入应集中在材料多样性而非约束遵守。

**（2）评测器自身也需要被评测。** 本轮评测最大的收获之一是抓到了评测系统的三个真实问题：J2 约束抽取从未收到真实 prompt（全部样本 J2 空洞高分，已修复并重评）；remove_track 退化在轴级不敏感（E1）；散拍退化实际被 A1 格式门拦截而非节奏轴（归因标签与实际检测层不符）。没有这轮实跑，这些都会成为"看起来很美"的评测盲区。

**（3）防御是分层的，读分也要分层。** 同一个"坏作品"可能被三层机制以不同方式拦截：A1 格式门（硬错误）、乘法反退化门（行为退化）、轴扣分（质量平庸）。只看 composite 会把"复读"（门拦）和"难听"（轴扣）混为一谈；报告分数时应附带"哪一层拦的"标签，这也是 results.csv 同时记录轴分与门乘数的原因。

**（4）密度是门击穿的第一驱动变量。** 逐样本统计显示 notes/bar 与 G_repetition 强负相关：classical（5–17 notes/bar）门均值 0.99；lofi（15–17）0.14–0.72；touhou（35–54）0.05–0.41。**反退化门的标定必须按风格密度归一化**，否则高密度风格被系统性歧视——这是评测公平性问题，不是模型能力问题，二者的解法完全不同。

**（5）背离样本是金矿。** r=0.057 的正交性意味着每个样本都能按"规则轨 × Judge"四象限定位，双高样本（规则轨和 Judge 都认可，如 classical_basic_01）是 few-shot 提示的优质素材，双背离样本（R=7.7/J=90）则精确指出规则体系或评委的盲区。


## 10. 局限性

- **生成与评判同源（已做异构交叉，偏置可控但有维度分化）**：E4 用异构模型对同 8 样本重评 J1–J3，composite 层面跨模型 Pearson = 0.934 / Spearman = 0.690——总分排序的可迁移性良好；但维度级 J3（音乐性）跨模型相关仅 0.073，且 Judge-A 在 J2（prompt 遵循）上系统性宽 ~6.6 分。结论：composite 总分可用于跨模型比较，单维度分（尤其 J3）只应在同 Judge 内部横向使用。
- **评委为单模型单次判定（已量化）**：E2-Judge 实测三轮重复的每维 mean(std) = 2.96 / 5.08 / 3.01、J3 档位加权 κ = 0.71、composite 单样本极差 ≤ 2.5——中等波动，排序结论可用；对分差 8 分内的样本采用多轮中位数缓解（清单化与锚点 rubric 是结构性缓解，非统计消除）。
- **符号指标 ≠ 听感（已做人工对照初步验证）**：R_rule 无法感知音色、演奏力度的人性化、混响空间感；J3 的 1–5 档即使有锚点也是模型的主观判断。分数应当作"筛选与回归工具"，不作"好听"的最终裁决。
- **规则阈值带风格假设**：density_ref、鼓型合法位置等参考值来自风格包的人工定义，阈值本身未经系统化的人类听感校准（见 evaluation.md「已知校准项」）。
- **样本规模**：46 样本、每类别 4–12 个，细分到风格 × 类别时统计功效有限，结论以趋势为主。
- **轻度退化方向不可靠**：E1b/E5 发现对低分样本施加音高随机化反而可能升分（随机 48–84 比原曲更贴合），评估器对"劣化方向"的判定在低分区间不单调；重度劣化检出可靠。
