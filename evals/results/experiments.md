# 有效性验证实验（E1 / E2 / E3）

- 基准作品：classical 风格 `Composition`，133 个音符 / 4 轨 / 24 小节
- 规则轨为纯确定性代码（不含 LLM），实验可完全复现

## E1 区分度实验

对基准作品施加四种退化操作，检查目标轴分数是否按预期下降（门槛值见 `ATTRIBUTION_TARGETS`）：

| 退化操作 | 目标轴 | 实际降幅（正值=分数下降） | 判定 |
|----------|--------|----------|------|
| scatter_pitch（音高随机化） | harmony | +0.515（门槛 ≥0.20） | ✓ |
| scatter_pitch（音高随机化） | voice | +0.387（门槛 ≥0.15） | ✓ |
| remove_track（删除末轨） | harmony | +0.015（门槛 ≥0.10） | ✗ |
| remove_track（删除末轨） | voice | +0.000（门槛 ≥0.10） | ✗ |
| scatter_onset（起拍抖动 ±60 tick） | rhythm | n/a | ✗ |
| repeat_first_bar（首小节复制全曲） | structure | +0.000（门槛 ≥0.15） | ✗ |
| repeat_first_bar（首小节复制全曲） | rhythm | +0.035（门槛 ≥0.10） | ✗ |

**E1 结论**：存在未达标项，评分器对某类退化不敏感。
