# E4 异构 Judge 消自我偏好实验

## 方法

- 8 个已完成评测样本（5 曲风 basic + constraint / hard / adversarial），冻结输入同 E2-Judge（SHA-256 见 JSON 冻结块）
- 同一批作品分别由 Judge-A（生成同源模型）与 Judge-B（Zen 免费档异构模型，型号见 JSON 冻结块）独立评分 J1/J2/J3，规则轨共用同一份结果

## 结果

| 维度 | Pearson | Spearman | Judge-A 均值 | Judge-B 均值 | 均值差 (A−B) |
|------|---------|----------|--------------|--------------|--------------|
| J1 | 0.680 | 0.527 | 69.375 | 65.125 | 4.250 |
| J2 | 0.585 | 0.588 | 76.875 | 70.250 | 6.625 |
| J3 | 0.158 | 0.073 | 48.750 | 52.500 | -3.750 |
| composite | 0.934 | 0.690 | - | - | - |

## 结论

两评委在 composite 层面 Pearson=0.934、Spearman=0.690。相关越高，说明「生成与评判同源」带来的自我偏好偏置越可控；均值差列可直接读出评委间的宽严差异。若某维度相关偏低，应将该维度分数仅用于横向对比而非绝对结论。
