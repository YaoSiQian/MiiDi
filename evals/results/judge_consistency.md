# E2-Judge 评委轨重复一致性实验

## 方法

- 从已完成评测的样本中选 8 个（5 曲风 basic 各 1 + constraint / hard / adversarial 各 1），冻结输入：composition.json 与 prompt 的 SHA-256 见 `judge_consistency.json` 冻结块
- 每样本独立重复 3 轮 J1/J2/J3（温度 0.0，与主评测一致）；规则轨为确定性代码，每样本只评一次
- Judge 为生成同源的单模型单评委，本实验度量的是其重复稳定性，不涉及与人工标注的一致性

## 汇总

- J1 mean(std) = 2.96，最大极差 8.00
- J2 mean(std) = 5.08，最大极差 25.00
- J3 mean(std) = 3.01，最大极差 21.00
- J1 清单逐项一致率均值：82%（按输出位置对齐，轮间项数不一致的样本如实保留 n/a 或截断对齐）
- J2 约束判定一致率均值：91%
- J3 档位二次加权 κ（合并成对比较）：0.71

## 结论

评委轨存在中等波动（mean(std) ≤ 8 分/百分制），排序与分组结论仍可用，但单分差异在 8 分内的样本不应据 Judge 单次评分定高下；已知缓解：对争议样本取多轮中位数。
